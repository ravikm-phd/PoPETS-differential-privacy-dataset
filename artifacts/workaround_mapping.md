# Mapping Workaround Categories to Missing Library Functionality

This document systematically maps each of the five workaround categories from our taxonomy to the specific missing operations and design gaps identified across IBM DiffPrivLib, PyDP, and OpenDP. Maintainers can use this lookup table to prioritize feature development and documentation guardrails.

---

| Workaround Category | IBM DiffPrivLib | PyDP (OpenMined) | OpenDP (Harvard) |
| :--- | :--- | :--- | :--- |
| **Mechanism Fallback** | Lacks high-level DataFrame predicate count helpers; developers bypass high-level tools to manually instantiate Laplace mechanisms (overlooking native `dp.count_nonzero`). | Lacks high-level Series/DataFrame aggregators; forces manual creation of 1D algorithm objects (e.g., `BoundedMean`) rather than DataFrame series methods. | Core API lacks top-level statistical helper wrappers (e.g., `dp.mean()`); developers fall back to constructing low-level transformation/measurement pipelines. |
| **Manual Re-implementation** | Completely lacks native DataFrame groupby; developers write manual loops over unique group keys with hand-managed budget splits ($\varepsilon/N$). | Lacks native grouped aggregation and automatic parallel composition tracking across disjoint subsets. | Core pipeline API lacks native group key extraction without discovering the separate Polars DataFrame integration (`opendp.Context`). |
| **External-Tool Delegation** | Accepts primarily 1D/2D numeric NumPy arrays; predicate filtering and string conversions (0/1 indicators) are delegated to pandas outside the DP boundary. | Strictly typed for numeric vectors (`int64`/`double`); cannot process string or categorical columns directly, forcing pandas pre-filtering. | Strict input domain and metric specifications push data ingestion, cleaning, and filtering into external non-DP Python/pandas code. |
| **Trial-and-Error Coercion** | Permissive defaults infer data bounds from data automatically, issuing a runtime `PrivacyLeakWarning` rather than blocking execution. | Enforces strict PyBind11 C++ numeric type constraints; developers repeatedly cast dtypes (`.astype(float)`) until runtime type errors resolve. | Surfaces low-level FFI runtime type error messages (`"expected i32, found String"`) to Python users, forcing trial-and-error pipeline chain rewrites. |
| **Parameter Guessing** | Inferring bounds derived from data issues a `PrivacyLeakWarning` without guiding developers toward domain bounds or private quantiles. | Requires mandatory bounds tuples (`lower_bound`, `upper_bound`) without safe estimation utilities or DP quantile helpers in Python, inviting data peeking. | Core API workflow lacks inline parameter selection guidance, causing developers to overlook built-in search utilities (`binary_search_param`) and make arbitrary budget guesses. |
